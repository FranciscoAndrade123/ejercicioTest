Arquitectura del Sistema

🏗️ Diseño Modular y Escalable

Nuestro sistema está diseñado con una arquitectura modular que separa las responsabilidades en tres módulos principales: Ventas, Productos e Inventario y Proveedores. Esta estructura facilita el mantenimiento, escalabilidad y futuras implementaciones de microservicios, siguiendo principios de Clean Code y buenas prácticas de desarrollo.
